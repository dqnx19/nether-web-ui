## API - create

```javascript
nwui.detailsPanel.create({
    parent: "", // HTML element
    id: "", // id 
    details: [
        {
            image: "", // detail image
            text: "" // detail text
        }
    ]
})
```

## API - addDetail

```javascript
nwui.detailsPanel.addDetail({
    parent: "", // details panel id
    image: "", // detail image
    text: "" // detail text
})
```

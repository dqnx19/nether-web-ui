## API - create

```javascript
nwui.tabs.create({
    parent: "",
    id: "",
    tabs: [
        {
            id: "",
            image: "",
            title: "",
            innerHTML: ""
        }
    ]
})
```

## API - addTab

```javascript
nwui.tabs.addTab({
    parent: "",
    id: "",
    image: "",
    title: "",
    innerHTML: ""
})
```

## API - displayTab

```javascript
nwui.tabs.displayTab({
    tabs: "",
    tab: ""
})
```

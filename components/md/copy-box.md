## API - Create
```javascript
copyBox.create({
    parent: "",
    id: "",
    language: "",
    code: "",
});
```

## API - changeLanguage
```javascript
copyBox.changeLanguage({
	id: "", // copy box id
	language: "" // language that will be set
})
```

## API changeCode
```javascript
copyBox.changeCode({
	id: "" // copy box id
	code: "" // code that will be set
})
```
